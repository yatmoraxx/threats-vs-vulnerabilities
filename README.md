# Threats vs Vulnerabilities

| No | Scenario | Category | Reasoning |
|----|----------|----------|-----------|
| 1 | A hacker sets up a fake free Wi-Fi hotspot at a café to capture users' login sessions. | Threat | Man-in-the-Middle (MitM) attack — an attacker intercepts data travelling between users and the network. |
| 2 | A university's student portal still uses HTTP instead of HTTPS for its login page. | Vulnerability | Unencrypted communication — login credentials are sent in plain text and can be intercepted. |
| 3 | Employees leave their computers unlocked when they go for lunch. | Vulnerability | Poor physical security practice — anyone nearby could access the system without authorization. |
| 4 | A cybercriminal sends SMS messages pretending to be a bank, asking users to click a link to "unblock" their account. | Threat | Smishing — SMS-based phishing designed to steal banking credentials. |
| 5 | A network router is still using the default admin username and password set by the manufacturer. | Vulnerability | Default credentials — easily guessed login details that attackers can use to take control of the device. |
| 6 | A disgruntled former employee uses an old account that was never deactivated to delete company files. | Threat | Insider threat — malicious action by someone who still has access after leaving the organization. |
| 7 | A mobile banking app stores user passwords in plain text on the phone. | Vulnerability | Insecure data storage — sensitive data is not encrypted and can be read if the device is compromised. |
| 8 | Attackers try thousands of password combinations per minute on a company's email login page. | Threat | Brute-force attack — automated guessing of passwords to gain unauthorized access. |
| 9 | A company does not keep any backup of its important business data. | Vulnerability | Lack of backup — data cannot be recovered after a ransomware attack, hardware failure or disaster. |
| 10 | A flood damages the server room of a company located near a river. | Threat | Environmental (natural) threat — physical damage that causes system downtime and data loss. |
